# Ezekiel Tony - Personal Resume Website

Personal resume website for the IIM Bangalore BBA (Digital Business and Entrepreneurship) Web Development course, styled with HTML5 and CSS3.

## Files
- `index.html` - page structure and content
- `style.css` - all styling (colors, typography, layout, responsive rules)

## CSS concepts used
Element, class and ID selectors; Google Fonts typography; color variables; margin, padding, border and border-radius; Flexbox (navbar, buttons, tags); CSS Grid (cards); sticky positioning (navbar); hover effects; media queries for mobile.

## Run locally
Open `index.html` in a browser.
